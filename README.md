# ClockCounter

Программа для проверки показаний счётчика времени.

## Скриншоты

![Главный экран ClockCounter](docs/screenshots/clock-counter-main.png)

На скриншоте — основной интерфейс приложения: отображение времени, кнопки старта/стопа, кнопка выбора стрелок и сброса.

## Важные нюансы сборки

Проект использует локальный репозиторий для артефакта `aapt2`, так как скачивание с `dl.google.com` может быть недоступно в ряде регионов.

### Что нужно сделать перед сборкой

1. Убедитесь, что рядом с папкой проекта существует папка `local-repo`, и в ней есть файлы:
   ```text
   local-repo/
     com/
       android/
         tools/
           build/
             aapt2/
               9.1.0-14792394/
                 aapt2-9.1.0-14792394-windows.jar
                 aapt2-9.1.0-14792394.pom
